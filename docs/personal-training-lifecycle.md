# Personal Training Client Lifecycle

Personal Training is the deepest workflow in the Hub. The system should support the relationship from first contact through long-term progression.

## Lifecycle

### 1. Lead / First Contact
Capture only what is useful:
- name
- contact
- how they found the trainer
- initial request
- preferred availability
- status

Do not perform a full assessment at this stage.

### 2. Onboarding
Create the client relationship and establish:
- objectives
- expectations
- availability
- training history
- relevant context and constraints
- communication preferences
- consent / required records

### 3. Initial Assessment
Create a baseline before prescribing a meaningful individual program.

Capture:
- primary and secondary goals
- current training level
- relevant history
- movement observations
- strengths
- limitations
- baseline performance
- measurements where appropriate
- subjective priorities
- trainer observations

The assessment should produce a concise **starting point** rather than becoming a form-filling exercise.

### 4. Goal Setting
Translate the client's desired outcome into actionable goals.

Each goal should have:
- goal type
- outcome
- priority
- target date
- success criteria
- current baseline
- status

Goals can change. The history should remain visible.

### 5. Program Design
Build the first personalised program from:
- assessment
- goals
- availability
- constraints
- methodology
- exercise library
- recovery considerations

The program should record why important choices were made, not only what exercises were selected.

### 6. Session Cycle
Each session follows:

**Prepare → Coach → Adapt → Capture**

Before:
- review previous session
- review current goal
- readiness / relevant context
- intended objective

During:
- planned exercises
- actual execution
- sets / reps / load / duration
- coaching observations
- modifications
- cues

After:
- outcome
- client feedback
- perceived effort
- relevant discomfort flags
- changes from plan
- trainer note
- next-session implication

### 7. Progress Review
At meaningful intervals:
- compare against baseline
- review goal progress
- review adherence
- identify what is working
- identify barriers
- reassess where necessary

The system should distinguish:
**measurement** from **interpretation**.

### 8. Adaptation
The trainer decides what changes.

Possible adaptation areas:
- exercise
- intensity
- volume
- frequency
- session structure
- recovery
- goal priority
- program duration

Record:
- what changed
- why it changed
- which evidence triggered the change
- effective date

### 9. Reassessment / New Program
When the current cycle ends:
- reassess
- close the program
- preserve history
- create the next program
- carry forward relevant learning

## Client lifecycle states

Lead → Onboarding → Active → Paused → Completed / Archived

A paused client must retain all history.

## Product principle

The Hub should help the trainer make better decisions without forcing the trainer to document everything.

Capture detail when it changes a decision.
Keep routine administration lightweight.
