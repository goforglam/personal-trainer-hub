# Example Trainer Day

This is a product-design example, not hard-coded data.

## Morning

### 08:00 — Personal Training
Before:
- review previous session
- check readiness
- confirm today's objective

During:
- deliver planned session
- adapt exercises where needed
- record meaningful observations

After:
- capture feedback
- mark session complete
- record next-session implication

### 10:00 — Admin / Programming
- update program
- review progress
- prepare upcoming sessions

## Afternoon

### 17:30 — Tae Bo
Group Fitness

Before:
- review class plan
- prepare music / equipment

During:
- teach class
- observe group energy and execution

After:
- attendance
- short class note
- record what to repeat/change

### 19:00 — DeepWork
Group Fitness

Same class-oriented workflow.

## Evening

### 20:30 — Personal Training
Individual client

Detailed individual session workflow.

## Key product insight

The trainer's day is not just a list of appointments.

Each appointment has a different depth of preparation, delivery and documentation.

Group Fitness:
prepare → teach → attendance → reflect

Personal Training:
prepare → assess → coach → adapt → document → progress
