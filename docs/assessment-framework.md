# Assessment Framework

The assessment model should be modular.

Do not create one giant questionnaire that every client must complete.

## Assessment layers

### Context
- goals
- training history
- availability
- lifestyle context
- constraints

### Movement / physical observation
The exact assessment modules should be defined by the trainer's methodology.

Potential modules:
- mobility
- stability
- movement quality
- strength / capacity
- coordination
- conditioning
- balance

### Baseline
Record only metrics that are relevant to the client's goals.

### Subjective
- confidence
- perceived limitations
- preferences
- motivation
- relevant feedback

### Trainer interpretation
A concise professional summary:
- strengths
- priorities
- considerations
- initial direction

## Design rule

Assessment is a decision-support tool.

It should answer:

1. Where is the client now?
2. Where do they want to go?
3. What matters most?
4. What should influence the training plan?

It should not become an administrative burden.
