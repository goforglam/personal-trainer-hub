# Personal Training Session Workflow

A Personal Training session is not simply an appointment with a list of exercises.

## Before

The trainer should see a compact pre-session brief:

- client
- current program
- current goal
- last-session outcome
- relevant recent progress
- readiness / context
- today's intended objective
- important coaching considerations

## During

The session view should prioritise speed.

The trainer needs to record:
- exercise
- planned prescription
- actual performance
- modification
- coaching cue
- observation

The interface should minimise typing while the trainer is coaching.

## After

The post-session capture should take less than a few minutes.

Suggested fields:
- session outcome
- client feedback
- perceived effort
- notable observations
- deviations from plan
- next-session action

## Smart distinction

Not every session needs every field.

The system should allow:
- quick completion for routine sessions
- deeper notes when something changed
- explicit flags when follow-up is needed

## Next-session intelligence

The most valuable output of a completed session is not the historical record.

It is:

**What should I remember when I see this client again?**

Therefore every completed PT session should produce a concise next-session summary.
